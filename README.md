# Radar Altimeter Three-Convolution Model Retracking

本项目实现了基于**三项卷积模型**的雷达高度计回波模拟与参数估计，提供了两种最小二乘反演策略：**联合估计**与**单参数估计**。代码使用Python编写，适合学术研究、教学演示及算法开发。

## 📌 项目背景

雷达高度计通过发射脉冲并接收海面回波，反演海面高度、有效波高（SWH）、误指向角等关键参数。本项目基于经典的**Brown模型**，实现了三项卷积回波生成，并利用**加权最小二乘**方法进行参数反演。

## 🧠 核心方法

### 三项卷积模型

回波波形由以下三个部分卷积而成：

1. **平坦海面冲激响应** \( P_{FS}(t) \)  
2. **海面高程分布** \( q_s(t) \)（含偏度与峰度修正）  
3. **系统响应** \( s_r(t) \)（高斯脉冲）

模型支持以下海面参数：

- `tau`：回波时延（相对于星下点）
- `P_u`：回波幅度
- `SWH`：有效波高
- `xi`：误指向角（离天底角）

### 反演方法

- **v3**：联合估计四个参数（时延、幅度、SWH、误指向角）
- **v4**：固定其他三个参数，仅估计SWH（精度更高）

采用**加权最小二乘**，权重基于信号功率与残差自适应调整，支持线搜索与学习率调度。

## 📊 示例结果

### v3：联合估计（四项参数）

- 时延 τ：估计精度较高
- 幅度 P_u：基本准确
- SWH：受耦合影响，精度略低
- 误指向角 ξ：高阶参数，估计困难

### v4：仅估计 SWH

- SWH 估计精度高
- 波形拟合效果良好
- 适合用于验证模型与算法稳定性

## 🚀 使用说明

### 环境依赖

- Python 3.7+
- NumPy
- SciPy
- Matplotlib

### 运行方式

```bash
# 四项参数联合估计
python "Brown Model Fit Estimate By LS v3.py"

# 仅估计 SWH
python "Brown Model Fit Estimate By LS v4.py"
```

运行后将生成回波波形图、收敛曲线图、参数对比图及拟合效果图。
